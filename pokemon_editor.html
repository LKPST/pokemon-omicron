Palette Swap Sheets

Folder A (reference) and Folder B (images to update) are paired by Sprite ID + name. Each pair becomes one sheet named gSprite<ID><Name>.png with four frames: A original · A with B's palette · B with A's palette · B original. Everything runs in your browser.

1Folder A – reference

Files named gFrontSprite / gBackShinySprite (…) + Sprite ID + Name, e.g. gFrontSprite001Bulbasaur.png. The ID and name are extracted from the file names.
Drop Folder A (or its files) here

2Folder B – images to update

Same naming format. Each file is tied to the Folder A file with the same Sprite ID and name, whatever the prefix (gFrontSprite001Bulbasaur ↔ gBackShinySprite001Bulbasaur).
Drop Folder B (or its files) here
