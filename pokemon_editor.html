Folder A (reference) and Folder B (images to update) are paired by Sprite ID + name. Each pair becomes one sheet named gSprite<ID><Name>.png with four frames: A original · A with B's palette · B with A's palette · B original. Everything runs in your browser.

1Folder A – reference

Files named gFrontSprite / gBackShinySprite (…) + Sprite ID + Name, e.g. gFrontSprite001Bulbasaur.png. The ID and name are extracted from the file names.

not loaded
Maps species to National Dex numbers (also loaded by Choose project folder or automatically when this page is served from the project). Species list comes from PokemonDatabase.js; if that is not loaded the Pokédex species are used.

2 · OW sprite folder

001.png = normal, 001s.png = shiny. Names with _0 or -Fighter are ignored. Each file is cut as 4×4 frames; only columns 2 and 3 are kept (rows: down, left, right, up).

3 · Spritesheet (for generations missing in the folder)

Frame sizes above are the sheet's base size = one grid cell. A Pokémon with a bigger size takes as many cells as it needs (e.g. 64px frames in a 32px sheet skip 3 cells) and the next Pokémon comes after it. Red boxes in the preview show exactly how the sheet is being cut.

4 · Fix wrong mappings (PLUS dex ID)

from dex #
Pokémon with dex D uses sprite file number D + offset + rules. A rule applies to every Pokémon from that dex number onward. Individual fixes: select a Pokémon below and step through the sprites.

5 · Output

One image: every Pokémon takes 4×4 frames (normal columns 1-2, shiny columns 3-4; rows down/left/right/up). Frames are located by x/y in OverworldSprites.js.
